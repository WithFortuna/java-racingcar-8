# java-racingcar-precourse

## 기능 목록

### 1. 사용자 입력
- 경주할 자동차 이름을 쉼표(,) 기준으로 입력받는다
- 시도할 횟수를 입력받는다

### 2. 입력 검증
- 자동차 이름은 5자 이하인지 검증한다
- 자동차 이름이 5자를 초과하면 예외를 발생시킨다

### 3. 입력 파싱
- 쉼표로 구분된 자동차 이름 문자열을 개별 이름 리스트로 변환한다

### 4. 경주 진행
- 입력받은 횟수만큼 경주를 진행한다
- 각 라운드마다 모든 자동차에 대해 다음을 수행한다:
  - 0에서 9 사이의 무작위 값을 생성한다
  - 무작위 값이 4 이상이면 전진한다
  - 무작위 값이 4 미만이면 정지한다
- 각 자동차의 현재 위치(전진 거리)를 관리한다

### 5. 경주 결과 출력
- 각 라운드가 끝날 때마다 모든 자동차의 이동 상태를 출력한다
- 자동차 이름과 전진한 거리만큼 '-'를 출력한다
- 형식: `자동차이름 : ---`

### 6. 우승자 판정
- 경주가 끝난 후 가장 많이 전진한 자동차를 찾는다
- 우승자가 여러 명인 경우 모두 출력한다
- 우승자 이름을 쉼표(,)와 공백으로 구분하여 출력한다
